# UiChemy AI Website Creator for Cursor and Grok Bot

Build a WordPress-ready website with AI from a brief, right from Cursor or Grok Bot. UiChemy drafts a multi-page site, you keep editing it in your own UiChemy account, then export it to Elementor or Gutenberg.

## What you can do

- Build a multi-page site from a brief, with layouts and copy that fit each section.
- Edit colours, fonts, buttons, cards, spacing, headings and body copy.
- Import an existing site from HTML, CSS and JS, a zip, or a Lovable, Bolt or v0 build.
- Add a blog or a custom section, and compare colour variants.
- Publish a live preview site on a UiChemy address.
- Export to Elementor or Gutenberg and import into your own WordPress site.

## Install

In Cursor, run `/add-plugin uichemy`. The plugin connects to the UiChemy MCP server at `https://app.uichemy.com/api/mcp` and asks you to sign in to your own UiChemy account.

## Pricing

You can start free: the Free plan builds one site. Paid plans start at $8/month, billed yearly. See https://uichemy.com/pricing/.

## Safety

- The plugin only reaches projects in the UiChemy account you connect.
- It asks for confirmation before anything that deletes, overwrites or publishes.
- It never asks for your WordPress password. For your own site you sign in yourself.
- It does not change DNS, domains or hosting.
